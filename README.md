# generate-finvoice-3-0-xml-invoice-python
This Python script demonstrates how to programmatically generate a basic Finvoice 3.0 e-invoice in XML format. It uses standard library features (`xml.etree.ElementTree` and `xml.dom.minidom`) to construct a minimal invoice structure, including seller/buyer details, invoice rows, and totals, saving it to a file. This illustrates creating e-invoices
